# ⚽ Platform de Gestion d'un Club de Football

Une application web complète conçue en **PHP Native (Architecture MVC)** pour simplifier la gestion administrative et sportive d'un club de football.

## 🚀 Fonctionnalités Principales

- **Gestion des Utilisateurs & Rôles :** Admin, Coaches, Staff technique, Joueurs.
- **Gestion des Joueurs :** Profils, statistiques, photos de profil.
- **Gestion de la Démo :** Protection des comptes d'administration principaux contre l'édition/suppression.
- **Espace Administrateur :** Tableaux de bord, modification des rôles et statuts.

## 🛠️ Technologies Utilisées

- **Back-end :** PHP 8 (PDO, Sessions, Hachage de mots de passe, protection CSRF)
- **Front-end :** HTML5, CSS3, JavaScript, Bootstrap 5, Bootstrap Icons
- **Base de données :** MySQL / MariaDB
